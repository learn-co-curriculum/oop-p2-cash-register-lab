# Object-Oriented Programming Lab: Cash Register

## Lab Overview

This lab implements a **CashRegister** class to simulate a cash register for an e-commerce site.  
It demonstrates object-oriented programming concepts, including attributes, methods, validation, and maintainable documentation.

---

## Features

- **Add items** to the register (`add_item(item, price, quantity)`)
- **Apply discount** to the total (`apply_discount()`)
- **Void the last transaction** (`void_last_transaction()`)
- Tracks **all items added** and **previous transactions**
- **Validates discount** input (must be an integer between 0–100)
- Includes **docstrings and comments** for maintainability
